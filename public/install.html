CORE MDM Installer

Install CORE MDM on an Android phone and set it as device owner — over a USB cable, by scanning a QR code, or with ADB commands you run yourself.

How do you want to install?

All three give the same result.

This browser can't connect to USB devices. Use Chrome or Edge on a computer, and open this page over https:// or localhost.
1

Get the phone ready

Do this once, before connecting.

  1. Factory reset the phone, or remove every account under Settings › Accounts. Android won't set a device owner while any account is on the phone.
  2. Skip Google sign-in during setup.
  3. Turn on developer options: Settings › About phone, then tap Build number 7 times.
  4. Turn on USB debugging in Settings › System › Developer options.
  5. Connect the phone with a USB cable. If you have ADB on this computer, close it first by running adb kill-server.
  6. Xiaomi / Redmi / POCO only: also turn on USB debugging (Security settings) in Developer options — needed for the permission step.

Samsung phone not showing up? On Windows, install the Samsung USB driver, unplug and replug the phone, then try again.

2

Connect

Choose the phone in the browser popup, then tap Allow on the phone's "Allow USB debugging?" prompt.

Scan the code
Point the phone's scanner at this code, then follow the prompts on the phone.

    

    
    
      
  1. The phone connects to Wi-Fi, downloads CORE MDM and sets it as device owner. This takes a minute or two.

You may need to finish it off with ADB. A QR setup can't give CORE MDM one permission that only ADB can grant. Without it, some phones' battery saver can pause CORE MDM and commands stop arriving. To add it, turn on USB debugging (Settings › About phone, tap Build number 7 times, then Developer options › USB debugging), connect the phone to a computer with ADB, and run:

      
adb shell pm grant com.core.mdm android.permission.WRITE_SECURE_SETTINGS

      
It prints nothing when it works. On Xiaomi / Redmi / POCO, also turn on USB debugging (Security settings). See the Manual (ADB) method for help with ADB.

Run these commands
Copy each one into the terminal, in order, and press Enter.

    

      
adb devices
Tap Allow on the phone's “Allow USB debugging?” prompt. The phone should be listed as device — not unauthorized.

      
adb install -r coremdm.apk
Should end with Success.

      
adb shell dpm set-device-owner com.core.mdm/.MdmDeviceAdmin
Should print Success: Device owner set to package com.core.mdm.

      
adb shell pm grant com.core.mdm android.permission.WRITE_SECURE_SETTINGS
Required. Prints nothing when it works. Lets CORE MDM stop the phone's battery saver from switching it off — without it, commands can stop arriving. On Xiaomi / Redmi / POCO, first turn on USB debugging (Security settings) in Developer options.

    Something went wrong?
    
    
      
  • “already some accounts on the device” — remove every account in Settings › Accounts (or factory reset). To see what's left:
    
      
    adb shell dumpsys account
    
      
    • 
      
  • “already several users on the device” — remove the work profile / extra users. List them, then remove each one that isn't 0:
    
      
    adb shell pm list users
    
      
    adb shell pm remove-user 10
    Replace 10 with the user number from the list.
    
      
    • 
      
  • Phone shows as unauthorized — unlock the phone and accept the USB debugging prompt. Still stuck? Run adb kill-server, unplug, replug.
    • 
      
  • Phone not listed at all — try another cable or port. On Windows with a Samsung phone, install the Samsung USB driver.
    • 
      
  • INSTALL_FAILED_UPDATE_INCOMPATIBLE — an old CORE MDM signed with a different key is installed. Remove it first:
    
      
    adb uninstall com.core.mdm
