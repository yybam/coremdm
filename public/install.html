CORE MDM Installer

Install CORE MDM on an Android phone and set it as device owner, over a USB cable or by scanning a QR code. Nothing to download to this computer.

How do you want to install?

Both ways give the same result.

This browser can't connect to USB devices. Use Chrome or Edge on a computer, and open this page over https:// or localhost.
1

Get the phone ready

Do this once, before connecting.

  1. Factory reset the phone, or remove every account under Settings › Accounts. Android won't set a device owner while any account is on the phone.
  2. Skip Google sign-in during setup.
  3. Turn on developer options: Settings › About phone, then tap Build number 7 times.
  4. Turn on USB debugging in Settings › System › Developer options.
  5. Connect the phone with a USB cable. If you have ADB on this computer, close it first by running adb kill-server.

Samsung phone not showing up? On Windows, install the Samsung USB driver, unplug and replug the phone, then try again.

2

Connect

Choose the phone in the browser popup, then tap Allow on the phone's "Allow USB debugging?" prompt.
