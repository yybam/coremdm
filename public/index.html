Why CORE MDM

Everything you need to keep a phone locked down

CORE MDM runs as device owner, the highest level of control Android allows an app — real restrictions, not settings a user can just switch back.

Remote commands

Lock the screen, sound a loud alarm to find a lost phone, reboot, or apply a full lockdown — all cancellable before the phone runs them.

App control

Block installing, uninstalling and sideloading. Hide the Play Store and browsers, block social media in one toggle, or hide any app from a synced inventory.

Tamper-proof

Block factory reset, safe mode and USB debugging, enforce a minimum lock-screen PIN, and protect CORE MDM from being uninstalled.

Content filter

A built-in DNS filter and enforced Private DNS keep web traffic going through the filter you choose — and on device-owner phones it starts with no on-device tap.

Kiosk mode

Lock the phone to only the apps you allow. Great for work phones, kids' phones, and single-purpose devices.

Live web console

See every phone with online/offline status and last seen. Changes apply the moment you flip a switch — no refresh, no re-sync.

How it works

Up and running in three steps

1

Install

Plug the phone into a computer and open our web installer, or scan our setup QR code on a freshly reset phone. Either way, CORE MDM is installed and set as device owner automatically.

2

Sign in

Open CORE MDM on the phone and sign in. The phone registers itself to your account automatically.

3

Manage

Open the web console with the same account. Your phone is there. Switch on the rules you want.
