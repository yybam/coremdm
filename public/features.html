Features

Real control, built on device owner.

Because CORE MDM runs as device owner, Android itself enforces the rules — they aren't settings a user can just switch back.

Remote commands

Lock the screen, sound a loud alarm to find a lost phone, reboot, or apply a full lockdown. Commands are queued and cancellable — stop one before the phone picks it up.

App control

Block installs, uninstalls and sideloading. Hide the Play Store and browsers. Block social media in one toggle, or hide any individual app from a synced inventory of what's on the phone.

Tamper-proof

Block factory reset, safe mode and USB debugging, block adding users, lock the status bar, enforce a minimum numeric lock-screen PIN, and protect CORE MDM from being uninstalled.

Content filter & DNS

A built-in DNS filter plus enforced Private DNS keep web traffic on the filter you choose, on Wi-Fi and mobile data. On device-owner phones the filter starts from the console with no on-device tap.

Kiosk mode

Lock the phone to only the apps you allow. Ideal for work phones, kids' phones, scanners and single-purpose devices.

Hardware & network

Lock Wi-Fi, Bluetooth, mobile network and VPN settings. Block USB file transfer, SD cards, adding users and outgoing calls. Disable the camera and screenshots.

Live web console

Every phone with online/offline status and last-seen. Rename devices, browse their installed apps, and watch changes apply in real time — no refresh, no re-sync.

Private to your account

Phones are tied to the account that signed in on them. Only you can see and manage your devices, and no one else's show up.

Works on any brand

Samsung, Google Pixel, Motorola, Xiaomi and more — any Android phone running Android 8.0 or newer.
